## Selected Projects

### AI Foundation Models for Gene Regulatory Networks
MSc research project at Hanze UAS / UMCG exploring pretrained transformer-based foundation models and supervised machine-learning methods for gene regulatory network prediction and potential therapeutic-target discovery.

### Vital Signs Analysis from VitalDB
Biomedical signal and time-series analysis project involving preprocessing, anomaly screening, smoothing, correlation analysis, ACF/PACF, and PELT change-point detection.

### Matcha Stress-Related Outcomes
Analysis of wearable, clinical, biological, and psychometric data from a randomised placebo-controlled crossover study using Python-based statistical analysis and visualisation.

### Wearther
Weather-based decision-support application developed with Python and Streamlit, translating weather forecasts into location- and time-aware recommendations for clothing and outdoor activities.

[Live Demo](https://wearthernl.streamlit.app/)
